# GitHub Repository Scope

This is the canonical public GitHub repository for LiveFaceSwap AI product documentation, public feedback, roadmap notes, support routing, and security guidance.

GitHub Issues are suitable for reproducible product problems and ideas that contain no private media, account information, billing data, credentials, or vulnerability details. The private website and desktop production source code is not mirrored here.

If an official platform mirror links back to this repository, product-wide roadmap and security decisions remain canonical here.
