# LiveFaceSwap AI Public Roadmap

This roadmap describes public product directions, not guaranteed release dates.

## Current Focus

- Make browser camera, reference, effect, model, and metered-rate states easier to understand.
- Improve Windows 11 and macOS Desktop setup and LiveFaceSwap Camera routing guidance.
- Improve Linux Desktop preview setup and compatibility guidance; Linux does not yet provide a virtual camera.
- Strengthen private-test, authorization, disclosure, and synthetic-media safety guidance.
- Improve support diagnostics without asking users to expose private faces, account details, or credentials.

## Exploring

- Broader compatibility guidance based on verified virtual-camera workflows.
- Better pre-session checks for network, camera, and credit readiness.
- Linux virtual-camera support, subject to implementation and real-device validation.
- More accessible documentation and localized public guidance.

## Feedback

Open a [public roadmap discussion](https://github.com/LiveFaceSwapAI/livefaceswap/issues) when the idea can be shared safely. For private account or media context, use [LiveFaceSwap AI support](mailto:support@livefaceswap.ai).
